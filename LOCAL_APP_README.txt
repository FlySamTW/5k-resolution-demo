5K / 4K / 2K / 1K display demo - local version

How to use on Windows:

1. Unzip this folder to any location.
2. Put your PNG, JPG, WEBP, MP4, WEBM, or MKV files into the images folder.
3. Double-click 啟動展示.bat.
4. The browser will open automatically.

How to update media:

- Add, remove, or replace files inside the images folder.
- Refresh the browser page to reload the media list.
- The app also checks the images folder periodically while it is open.
- MKV files are listed as videos, but playback still depends on the browser and the codec inside the file. MP4 / H.264 is the safest format for demos.

Notes:

- Keep index.html, 啟動展示.bat, launch-demo.ps1, start-demo.ps1, LOCAL_APP_README.txt, and the images folder together.
- This local package does not include cloud images or videos.
- If Windows shows a security prompt, allow the script to run.
