5K / 4K / 2K / 1K display demo - local version

How to use on Windows:

1. Unzip this folder to any location.
2. Put your PNG, JPG, WEBP, MP4, or WEBM files into the images folder.
3. Double-click 啟動展示.bat.
4. The browser will open automatically.

PrintScreen capture:

- When 啟動展示.bat is used, the PrintScreen watcher starts together.
- Press PrintScreen anywhere in Windows.
- The screenshot will be saved into the images folder automatically.
- The demo page will detect it and select the new screenshot.

Notes:

- Keep index.html, 啟動展示.bat, start-demo.ps1, watch-printscreen.ps1, and the images folder together.
- This local package does not include demo images or videos.
- If Windows shows a security prompt, allow the script to run.
- PrintScreen auto capture works only on Windows local mode. It does not work on cloud, iOS, or Android browsers.
